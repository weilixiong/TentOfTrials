# Log Parser Fixtures

This directory contains independent, hand-written log parser fixtures for validating the log aggregation parsers in `log_aggregator.py`.

## Purpose

The legacy log aggregator test suite had a 40% false pass rate because test data was generated by the same parser code being tested. These fixtures address that issue by providing independent, representative log lines written by hand.

## Files

- `parser_fixtures.py` - Hand-written fixture data for JSON, plain text, and nginx log formats
- `test_parser_fixtures.py` - Validation script that tests parsers against the fixtures

## Fixture Coverage

### JSON Log Parser (4 fixtures)
- Standard JSON with `timestamp` field
- JSON with `time` field alias
- JSON with `@timestamp` (Elasticsearch format)
- Minimal JSON without timestamp

### Plain Text Log Parser (4 fixtures)
- Service name in brackets with ISO8601 timestamp
- Service name in brackets with standard timestamp
- Uppercase service name followed by colon
- Plain text without explicit service

### Nginx Log Parser (3 fixtures)
- Successful GET request (200 status)
- 404 Not Found (warning level)
- 500 Internal Server Error (error level)

### Malformed/Unsupported Lines (5 fixtures)
- Invalid JSON structure
- Empty lines
- Incomplete nginx format
- Random text without log structure
- Binary-like content

## Running Tests

```bash
cd tools/tests
python3 test_parser_fixtures.py
```

Expected output: All validation tests should pass.

## Implementation Notes

The fixtures were designed based on the actual regex patterns in `log_aggregator.py`:

- **Service extraction**: Uses `\[(\w+)\]` pattern (only word characters, no hyphens) or `(\w+)\s*:` for uppercase services
- **Timestamp patterns**: Supports ISO8601, standard format, nginx format, and syslog
- **Level patterns**: Matches ERROR/FATAL/CRITICAL, WARN/WARNING, INFO/NOTICE, DEBUG/TRACE

These fixtures provide focused validation of the main parser paths without relying on parser-generated samples, ensuring that regressions in log format handling are caught.
